# Stage 3 slideshow photos

Put slideshow images in this folder as JPG files, for example:

- `step-three-image-1.jpg`
- `step-three-image-2.jpg`
- `step-three-image-3.jpg`

Then edit the `SLIDESHOW_IMAGES` array at the top of `src/stages/ThirdStage.jsx` to list the files that actually exist.

The images are served from paths such as `/step-three-images/step-three-image-1.jpg`. The array order is the slideshow order.
